# 🔄 UVA Trading App

An app that facilitates barternig between students.

## 🛠️ Development

Create a virtual environment (if you haven't)

```
python -m venv venv
```

Activate your new python environment:

**Windows**

```
venv\Scripts\venv
```

**Mac/Linux**

```
source venv/bin/activate
```

Install all the requirements:

```
pip install -r requirements.txt
```

Everything should be setup at this point and you can run the project with:

```
# Make sure to move into the tradingapp directory
# cd tradingapp
python manage.py runserver
```
